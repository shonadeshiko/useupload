# 流域が沈黙して壊れる — 開発判断の連鎖シミュレータ

AIエージェント社会シミュレーションハッカソン Vol.2 提出プロジェクト。

多摩川流域(東京都内、約1,095km²・4,381メッシュ)を対象に、**気候変動シナリオ(SSP1-2.6 /
SSP5-8.5)に応じた人口動態が、市街地化・農地/森林の管理放棄という土地利用変化を通じて
流出係数(＝内水氾濫リスク)にどう波及するか**を、決定論的な数値シミュレーション(層B)と
ローカルLLMエージェントによる議論支援(層A)の2層構成で可視化するプロトタイプ。

## デモの動かし方

1. `index.html` をブラウザで直接開く(サーバー不要、データは埋め込み済み)。
   GitHub Pagesで公開している場合は、公開URLに直接アクセスするだけでよい。
2. 地図・年スライダー・SSPシナリオボタンで土地利用変化のシミュレーションを操作できる。
3. AIエージェント機能(任意)を使う場合:
   - **ローカルOllama**: `ollama pull qwen2.5:1.5b` の上、
     `OLLAMA_ORIGINS=*` を設定して `ollama serve` を起動(CORS対応)。
   - **ブラウザ内WebGPU(WebLLM)**: Ollamaのインストール不要。WebGPU対応ブラウザ
     (Chrome等)で自動的にモデルをダウンロードして動作する(初回のみ数十秒)。
   - どちらもUI上のラジオボタンで切り替え可能。

## 構成

```
├── index.html                      # ダッシュボード本体(自己完結HTML)
├── 00〜12 (*.md)                  # 設計・検証・意思決定の記録(ドキュメント)
├── scripts/                       # GISデータ前処理パイプライン(実行可能)
│   ├── 01_extract_tama_watershed.py      # 多摩川水系の流域界抽出
│   ├── 02_clip_landcover_and_mesh.py     # 500mメッシュのクリップ・土地被覆ゾーン統計
│   ├── 03_compute_runoff_and_export.py   # 流出係数の算出・ダッシュボード用JSON出力
│   ├── 04_integrate_ssp_population.py    # SSP人口シナリオの統合
│   ├── 06_agent_layer_prototype.py       # LLMエージェント層(層A)のプロトタイプ
│   └── 07_robustness_check.py            # LLM出力の頑健性検証スクリプト
├── data/                           # 入力・中間データ配置用(実データ非公開、README参照)
└── _*.json                         # 実行ログ(頑健性検証・エージェント層のサンプル出力)
```

## データ出典(すべて一次情報)

- 国土数値情報 W12(流域界・非集水域)、500mメッシュ別将来推計人口
- JAXA High-Resolution Land Use and Land Cover map(HRLULC) 2022年
- 平成16年国土交通省告示第521号(土地利用形態別流出係数)
- 日本版SSPマニュアル第2版(国立環境研究所、地域区分別SSP人口比)

各データの前提・近似手法・既知の限界は各スクリプトのdocstring、および
`05-気候変動シナリオ×土地利用変化-分析手法.md` に詳しく記載している
(捏造・誇張なしのエビデンス主義を徹底)。

## 既知の限界(正直な開示)

- SSP人口シナリオは、本流域固有の1kmメッシュ推計ではなく、全国集計値の地域区分別比率を
  局所適用した近似(詳細は `04_integrate_ssp_population.py` docstring)。
- ローカルLLM(qwen2.5:1.5b等の小型モデル)は、具体的な数値を聞かれた際に実在しない
  メッシュIDを創作することがある(検証済み)。コード側のガードレールで検出・警告表示する
  多層防御を実装しているが、完全な防止を保証するものではない。
- JAXA土地被覆分類と告示521号のカテゴリ対応は開発者による解釈であり、告示に直接の
  対応表があるわけではない(詳細はスクリプトのdocstring参照)。
